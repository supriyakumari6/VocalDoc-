#  VocalDoc – Text to Speech Generator

##  Overview

VocalDoc is a simple web-based application that converts text into speech using a Flask backend and Murf API.
The main goal of this project was to build a fast and efficient system that can take user input and generate multiple audio outputs in real times.


##  Features

* Convert text into natural-sounding speech
* Generates 4+ audio outputs for a single input
* Fast API response with smooth data flow
* Simple and clean user interface

---

## Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Flask (Python)
* **API:** Murf API (Text-to-Speech)

---

##  How It Works

1. User enters text in the input field
2. The request is sent to the Flask backend
3. Backend processes the text using Murf API
4. Multiple audio outputs are generated and returned
5. User can listen/download the audio
